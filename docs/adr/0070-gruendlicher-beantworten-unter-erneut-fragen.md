# 0070: „Gründlicher beantworten“ steht unter „Erneut fragen“

- **Datum:** 2026-11-15
- **Status:** angenommen

## Kontext

Jede Antwort hat das Menü „Erneut fragen“ mit Wahl der Stufe (ADR 0064). Offen war, ob eine Antwort der Stufe Schnell zusätzlich einen eigenen Knopf für eine höhere Stufe bekommt.

## Betrachtete Optionen

1. **Eigene Empfehlung:** als erster Eintrag unter „Erneut fragen“.
2. Eigener Knopf an jeder schnellen Antwort.
3. **Disruptiv:** der Knopf erscheint nur, wenn die Antwort unsicher wirkt.

## Entscheidung

Option 1: Bei einer Antwort der Stufe Schnell steht „Gründlicher beantworten“ als erster Eintrag im Menü „Erneut fragen“.

## Folgen

- Kein zusätzlicher Knopf an der Antwort.
- Die Aktion gilt nur für diese Frage (ADR 0065) und bietet den Download an, wenn das Modell der höheren Stufe fehlt (ADR 0058).
